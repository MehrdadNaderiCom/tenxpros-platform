# Exam-to-Lesson Coverage Matrix

Deliverable 2 of the launch-readiness set. For each exam-bearing module, every one of the 12 exam questions is mapped to the concept it tests and whether that concept is taught in the same module's lesson. A question is counted as covered only if a partner who read the lesson could answer it from the lesson (no outside knowledge).
